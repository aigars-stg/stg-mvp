## The Short Version

**Grade honestly. Sell faster. Keep everyone happy.**

When you grade your game accurately, buyers know exactly what they're getting. No surprises, no disputes, no disappointment. A well-graded listing sells faster and builds your reputation as a trusted seller.

┌─────────────────────────────────────────────────────────────────┐
│ 🎯 **The golden rule**                                          │
│                                                                 │
│ If you're debating between two grades, pick the lower one.      │
│ A buyer who receives better than expected is delighted.         │
│ A buyer who receives worse than expected opens a dispute.       │
│ Under-promise, over-deliver.                                    │
└─────────────────────────────────────────────────────────────────┘

## The Four Grades

We use four condition grades. Stick to these — inventing terms like "Near Mint" or "Excellent" just makes comparison harder.

### Like New

**80–95% of retail value**

*Appears unplayed or played once*

Opened but essentially untouched. This game looks like you just removed the shrink wrap. Many games get opened, admired, and put on the shelf — if that's your game, this is probably the right grade.

| ✓ Like New means | ✗ Not Like New if |
|------------------|-------------------|
| Cards never shuffled | Any visible card wear |
| Components in original packaging | Components loose in box |
| No visible wear anywhere | Box has shelf wear or dings |
| Rulebook pristine | Rulebook has creases |

### Very Good

**60–75% of retail value**

*Played with care, minimal wear*

Played and enjoyed, but handled with care. A game in Very Good condition is what you'd happily give as a gift.

┌─────────────────────────────────────────────────────────────────┐
│ 🎁 **The gift test**                                            │
│                                                                 │
│ Would you wrap this game and give it to a friend without        │
│ apologizing for its condition? If yes, it's Very Good.          │
└─────────────────────────────────────────────────────────────────┘

| ✓ Very Good means | ✗ Not Very Good if |
|-------------------|-------------------|
| Light play, handled with care | Heavy or frequent play |
| Cards show minimal edge wear | Cards show obvious shuffling wear |
| Box has minor shelf wear only | Box has crushed corners or tears |
| All components present | Anything missing or replaced |

### Good

**40–55% of retail value**

*Regular play wear, fully functional*

Clearly pre-loved — this game has seen regular play but remains fully functional. All the adventures, some of the wear.

| ✓ Good means | ✗ Not Good if |
|--------------|---------------|
| Visible wear but plays perfectly | Wear affects gameplay |
| Cards show shuffling wear | Cards are sticky or damaged |
| Box shows wear (soft corners, scuffs) | Box is falling apart |
| All components present and functional | Components missing or broken |

### Acceptable

**20–35% of retail value**

*Heavy wear, still playable*

Well-loved and showing it. This game works, but it's seen better days.

┌─────────────────────────────────────────────────────────────────┐
│ ⚠️ **Acceptable requires extra honesty**                        │
│                                                                 │
│ Always note what's worn, missing, or damaged in your listing.   │
│ Buyers choosing Acceptable expect issues — just tell them       │
│ exactly what those issues are.                                  │
└─────────────────────────────────────────────────────────────────┘

| ✓ Acceptable means | ✗ Below Acceptable |
|--------------------|-------------------|
| Heavy wear but playable | Unplayable or major components missing |
| May have minor component issues | Game-breaking damage |
| Box may be taped or repaired | Box destroyed beyond use |
| Some wear on all components | Components unusable |

## Quick Reference Table

| Grade | Description | Typical Value |
|-------|-------------|---------------|
| **Like New** | Opened but unplayed, no wear | 80–95% of retail |
| **Very Good** | Played with care, minimal wear | 60–75% of retail |
| **Good** | Regular play wear, fully functional | 40–55% of retail |
| **Acceptable** | Heavy wear, possible minor issues | 20–35% of retail |

**Note:** Value percentages are rough guidelines. Rare and out-of-print games often sell for more regardless of condition.

## Special Considerations

Some aspects of board game condition need extra explanation.

### Punched vs. Unpunched Tokens

Whether cardboard tokens have been removed from their sheets matters to some buyers.

| Term | Meaning |
|------|---------|
| **Unpunched** | Tokens still in original sheets, never removed |
| **Punched** | Tokens removed from sheets (standard for any played game) |
| **Cleanly punched** | Removed carefully, no lifting or tearing |
| **Roughly punched** | Some lifting, tearing, or white edges visible |

Always mention if a game is unpunched — it's a selling point for collectors.

### Sleeved Cards

Cards protected in sleeves are a plus. Note this in your listing:

- Cards sleeved since purchase (never shuffled unsleeved)
- Cards sleeved after some play (mention any pre-sleeve wear)
- Whether sleeves are included or will be removed before sale

### Painted Miniatures

Some buyers want painted minis, others specifically don't. Be clear:

| State | How to describe |
|-------|-----------------|
| **Unpainted** | Original, unmodified |
| **Primed** | Base coat only, ready for painting |
| **Partially painted** | Some minis done, some not |
| **Fully painted** | Describe quality: tabletop standard, display quality |
| **Modified** | Converted or customized in any way |

### Promos & Extras

Promotional content, Kickstarter extras, or expansion material adds value — make sure buyers know:

- List specific promos by name
- Note if it's a Kickstarter or retail edition
- Mention bonus components not in retail version
- You can price valuable promos separately

### Edition & Language

Edition matters a lot. Different editions can have different components, art, or rules.

| Always specify | Why it matters |
|----------------|----------------|
| **Edition** | 1st, 2nd, Revised, Collector's, etc. |
| **Publisher** | Different publishers = different components |
| **Language** | Language of rules and any card text |
| **Language-independent?** | No text on components = playable in any language |

## Listing Description Examples

### Like New

> "Opened to read the rules, never played. All components still in original packaging. Cards never shuffled. Stored flat on a shelf in a smoke-free home."

### Very Good

> "Played maybe five times. Cards sleeved from first play, no wear. All components present. Original insert intact. Box shows minor shelf wear on corners."

### Good

> "Box shows shelf wear and one soft corner. Inside is in great shape — cards show light edge wear from shuffling. All components present and functional."

### Acceptable

> "Box has significant wear and a taped corner. Components are all there and play fine, but cards show shuffling wear and rulebook has some creases. Good candidate for sleeving the cards."

## Photos Make the Difference

Good photos build trust. Here's what to show:

| Photo | What to capture |
|-------|-----------------|
| **1. Box front** | Straight on, good lighting — shows the game and any wear |
| **2. Box back** | Shows edition info and component list |
| **3. Box corners** | If there's wear, show it honestly |
| **4. Components spread** | Everything laid out — shows what's included |
| **5. Any damage** | Close-ups of specific issues buyers should know about |
| **6. Cards** | Show edge wear if present — that's where wear shows first |

┌─────────────────────────────────────────────────────────────────┐
│ 📸 **Photo tips**                                               │
│                                                                 │
│ • Natural daylight works best                                   │
│ • Use a plain background (table, floor, solid color)            │
│ • Show actual condition, not the best angle                     │
│ • If something's wrong, photograph it — hiding it causes        │
│   disputes later                                                │
└─────────────────────────────────────────────────────────────────┘

## Common Grading Mistakes

| ❌ Mistake | ✅ Reality |
|-----------|-----------|
| "It's old, so it must be worn" | Age ≠ condition. A 20-year-old game stored well can be Like New. A 2-year-old game from 50 game nights might be Good. |
| "The box doesn't matter" | It matters to collectors. Many buyers care about box condition for display. Grade it honestly. |
| "Complete means nothing's missing" | Complete also means original. If you've replaced dice or printed new player aids, note it. |
| Inventing grades like "Near Mint" | Stick to our four grades. Custom terms make comparison harder for buyers. |
| Grading based on what you paid | A €100 game in rough shape is still Acceptable. Grade the actual condition, not the value. |
| Grading based on rarity | A rare game in poor condition is still in poor condition. Rarity affects price, not grade. |

## Frequently Asked Questions

### What if my game is between two grades?

**Go with the lower one.** Buyers who receive better than expected leave great reviews. Buyers who receive worse than expected open disputes.

### Does the original insert matter?

To some buyers, yes. If the insert is missing, damaged, or you've replaced it with a foam organizer, mention it. Some buyers specifically want the original insert; others don't care at all.

### What about replacement components?

If you've replaced anything — dice, player aids, cards — note it in your description. "Complete" means original components, not replacements.

### Should I clean the game before selling?

Yes, if needed. Wipe down the box, remove dust, clean any sticky residue. Don't try to repair damage though — just disclose it honestly.

### Can I sell a game with missing components?

Yes, but:
- Grade it as Acceptable (or don't list it if too much is missing)
- List exactly what's missing in your description
- Price accordingly — buyers expect a significant discount

### What if the game has been modified?

Modifications (painted minis, replaced components, custom inserts) should always be disclosed. Some modifications add value; some reduce it. Let buyers decide.

## The Bottom Line

| Do this | Not this |
|---------|----------|
| Grade based on actual condition | Grade based on how much you paid |
| Show problems in photos | Hide damage with clever angles |
| Describe wear specifically | Use vague terms like "some wear" |
| Pick the lower grade if unsure | Optimistically round up |
| Mention everything that's not original | Assume buyers won't notice |
